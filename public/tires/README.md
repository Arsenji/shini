# Фото шин для каталога

Положите сюда файлы и укажите путь в `src/data/shop/products.ts`:

```ts
{
  id: 'kumho-es31',
  // ...
  image: '/tires/kumho-es31.webp',
  price: 5200, // или не указывайте — будет «Цена по запросу»
}
```

Рекомендуемые имена файлов = id товара:
- kumho-es31.webp
- landsail-ls388.webp
- delinte-ds2.webp
- ...
